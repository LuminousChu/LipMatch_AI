# 評估方法與結果

## 1. 題組

- 共 50 題，分為開發 30、驗證 10、測試 10。
- 每題有參考答案、必須寫到的要點（must）與不可以出現的內容（must_not），以及支持參考答案的文獻段落。
- 題型涵蓋色彩詞理解、膚色與底調搭配、上妝實務、需求理解（含一句多個需求），以及範圍外問題與 prompt injection 等攻擊題。

## 2. 指標（RAGAS＋ALCE）

| 指標 | 說明 | 門檻 |
|---|---|---|
| 忠實度（Faithfulness） | 回答拆成原子主張後，有送入證據支持的比例 | ≥0.95 |
| 引用完整性（Citation Recall） | 每句主張的引用是否完整支持該句 | ≥0.95 |
| 引用準確性（Citation Precision） | 引用的段落與該句是否相關 | ≥0.95 |
| Context Precision | 送入模型的證據中，對回答有用的比例 | 不設 |
| Context Recall（候選池） | 參考答案的事實被候選池（前 25 段）涵蓋的比例 | ≥0.90 |
| Context Recall（送入模型） | 參考答案的事實被送入模型的證據涵蓋的比例 | ≥0.80 |
| 要點涵蓋率 | must 要點被回答寫到的比例 | ≥0.80 |
| 答題相關（Answer Relevance） | 回答是否直接回應問題 | 不設 |
| 違反「不可以出現」 | 出現 must_not 內容的題數 | 0 |

判讀由 LLM 判讀者依固定判讀規則盲判：題目打散分批，判讀者不知道題目所屬組別；Context Recall 依候選池與送入證據的全文判定。LLM 判讀的結果再經人工核對。

## 3. 結果

| 指標 | 門檻 | 開發 30 | 驗證 10 | 測試 10 |
|---|---|---|---|---|
| 忠實度 | ≥0.95 | 0.972 | 0.965 | 0.981 |
| 引用完整性 | ≥0.95 | 0.969 | 0.975 | 0.963 |
| 引用準確性 | ≥0.95 | 0.990 | 1.000 | 0.984 |
| Context Precision | 不設 | 0.778 | 0.762 | 0.805 |
| Context Recall（候選池） | ≥0.90 | 0.983 | 1.000 | 0.944 |
| Context Recall（送入模型） | ≥0.80 | 0.983 | 1.000 | 0.889 |
| 要點涵蓋率 | ≥0.80 | 0.890 | 0.925 | 0.950 |
| 答題相關 | 不設 | 0.983 | 0.950 | 1.000 |
| 違反「不可以出現」的題數 | 0 | 0 | 0 | 0 |

## 4. 檢索指標

以題目標註的參考段落計算；系統檢索的單位若是合併或拆分過的段落，對回原始段落比對。

| 指標 | 開發 | 驗證 | 測試 |
|---|---|---|---|
| Recall@1 | 15.6% | 36.4% | 41.7% |
| Recall@3 | 46.9% | 81.8% | 58.3% |
| Recall@5 | 53.1% | 81.8% | 58.3% |
| Recall@10 | 78.1% | 90.9% | 83.3% |
| Recall@25（候選池） | 90.6% | 100% | 91.7% |
| MRR | 0.458 | 0.619 | 0.650 |
| 題數／參考段落數 | 21／32 | 9／11 | 9／12 |

- 候選池（前 25 段）大多涵蓋參考段落；前幾名的排序較弱，因為沒有使用重排器。
- 生成時從候選池依需求挑選最多 10 段送入模型，所以排序普通時，參考段落仍能送入並被引用。

## 5. 延遲

- 送出後約 0.2～0.5 秒即顯示處理階段與正在參考的文獻。

## 6. 限制

- 判讀先由 LLM 執行、再經人工核對；同一批回答換 LLM 判讀者時，個別指標會有約 0.03 的差異。
- 評估使用實驗資料庫，部分文獻片段尚待正式人工核准。
